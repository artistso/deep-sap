Tracking mathematics is now in the Rust core

The previous key-based satellite demo has been retired. The executable now uses per-track noisy bearing observations, forward-ray geometry, nonlinear weighted least squares, covariance inversion, and 95% uncertainty ellipses.

Truth world → noisy observations → association → per-track fix → covariance → prediction

No satellite location is treated as a submarine bearing, and no provider API key is stored in the browser.
