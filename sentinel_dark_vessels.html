Sentinel integration moved server-side

The former browser credential and OAuth-token demonstration has been disabled. This application does not accept, store, or relay Copernicus usernames, passwords, access tokens, or refresh tokens.

A future integration must run in a private authenticated backend using a supported Copernicus OAuth or service-account flow. The browser should receive only derived, non-sensitive environmental metadata or approved imagery.

/sentinel/token and browser query-string token routes are intentionally retired.
