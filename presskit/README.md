# DEEP SAP Press Assets

DEEP SAP is an unclassified synthetic ocean sensor-fusion game and engineering testbed built with Rust, Bevy ECS, and WebAssembly.

Approved description:

> Study noisy synthetic bearings, build track hypotheses, and evaluate uncertainty in a tablet-first simulation. Public ocean observations may change environmental context, but all contacts are generated inside the game.

Do not describe the project as real target detection, operational ASW, dark-vessel detection, navigation software, or formal compliance with a government architecture.
