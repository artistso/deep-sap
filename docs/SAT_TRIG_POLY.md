# Archived Satellite/Polynomial Experiment

Satellite catalogue and imagery experiments are not part of the release module tree. Public satellite metadata is not a measurement of a synthetic game target and must not be inserted as a pseudo-bearing or range constraint.

The release tracker uses only simulated sensor observations whose observer position, bearing uncertainty, and timestamp are explicitly represented. Polynomial fitting is retained as a numerically stable utility; track motion currently derives from estimated fixes rather than hidden truth.

Any future remote-sensing research belongs in a separate, clearly scoped public-data visualization project with its own licensing, validation, and privacy review.
